How it works:
1. Press START CALIBRATION. The buoy asks for north first.
2. Aim the bow at the direction being asked for, using an external compass, and press SET.
3. It advances 45° on its own. Repeat until all eight are captured.
4. Press SAVE. Until then nothing on the buoy has changed, and CANCEL costs nothing.
North is the reference: it goes into the compass offset, so entry 0 is always 0 and north stays true even with the correction off.

Compass Calibration Table (8 reference points)

One guided run, north first. North sets the reference and lands in the compass offset, so the first table entry is 0 by construction - that is what keeps north true when the correction is switched off. Every following direction is measured against that same north. The value captured is Imag, the heading after the iron correction but before this table and before the trim, so nothing has to be switched off first and the buoy keeps steering throughout. Nothing is written until SAVE.

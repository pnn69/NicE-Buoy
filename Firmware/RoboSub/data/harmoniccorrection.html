How it works:
1. Align the buoy bow exactly towards a known reference direction (e.g. 90° East).
2. Locate the corresponding 90° card below, and click its Record button.
3. The system will capture your current active heading and save it as the measured value for 90°.
4. Repeat this for all 8 reference directions. The system automatically fits a smooth Fourier harmonic curve!
5. Click Save to ESP32 NVS once finished to permanently write the table to memory.
